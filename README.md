# Лабораторная работа: классификация с помощью дерева решений

Проект реализует бинарную классификацию дохода на наборе Census Income / Adult из UCI Machine Learning Repository.

Главное ограничение соблюдено: дерево решений реализовано самостоятельно в `src/decision_tree.py`. `sklearn.tree.DecisionTreeClassifier` не используется. Метрики также реализованы вручную в `src/metrics.py`.

## Подготовка данных

Загрузчик учитывает особенности Adult Dataset:

- разделитель `,`;
- пробелы после запятых;
- пропуски `?`;
- первая служебная строка в `adult.test`;
- точка в конце тестовых меток `<=50K.` и `>50K.`;
- смешанные числовые и категориальные признаки.

Строки с пропущенными значениями удаляются. Для лабораторной это простой и объяснимый способ обработки `?`: модель обучается только на полных наблюдениях. Целевая переменная `income` не попадает в признаки.

Дополнительно создаются CSV-преобразования:

- `results/csv/adult_train_clean.csv`;
- `results/csv/adult_test_clean.csv`;
- `results/csv/adult_train_encoded.csv`;
- `results/csv/adult_test_encoded.csv`.

Encoded-файлы используют one-hot encoding для категориальных признаков и нужны как проверяемый результат преобразования данных. Самописное дерево работает с исходными числовыми и категориальными признаками напрямую.

## Реализация дерева

Класс `DecisionTreeClassifierScratch` поддерживает интерфейс:

```python
tree.fit(X_train, y_train)
predictions = tree.predict(X_test)
```

Узел `TreeNode` хранит:

- признак разбиения;
- условие;
- дочерние узлы;
- класс большинства;
- число объектов;
- распределение классов;
- значение критерия для выбранного разбиения.

Числовые признаки разбиваются по порогу `feature <= threshold`. Пороги выбираются между соседними различающимися значениями, где меняется класс. Это сохраняет смысл алгоритма и ускоряет обучение.

Категориальные признаки разбиваются бинарно: `feature == value` против всех остальных значений. Если при предсказании встречается неизвестное категориальное значение, используется переход в ветку "остальные"; если ветка недоступна, возвращается класс большинства текущего узла.

## Критерии

Поддерживаются три критерия:

- `information_gain`: максимизируется прирост информации на основе энтропии.
- `gain_ratio`: максимизируется `InformationGain / SplitInformation`; деление на ноль обрабатывается как нулевой выигрыш.
- `gini`: максимизируется Gini Gain, то есть `Gini(parent) - weightedGini(children)`.

## Ограничения роста дерева

Параметры по умолчанию:

- `max_depth=8`;
- `min_samples_split=50`;
- `min_gain=1e-9`;
- `max_numeric_thresholds=128`.

Они нужны, чтобы дерево не переобучалось слишком сильно и строилось за разумное время на обычном ноутбуке. Визуализация показывает только первые 4 уровня, потому что полное дерево даже при ограниченной глубине плохо читается на одном изображении.

## Запуск

Установка зависимостей:

```bash
python3 -m pip install -r requirements.txt
```

Один запуск модели:

```bash
python3 main.py \
    --data data/adult.data \
    --test-data data/adult.test \
    --criterion information_gain \
    --max-depth 8 \
    --min-samples-split 50
```

Случайное стратифицированное разбиение `adult.data`:

```bash
python3 main.py \
    --data data/adult.data \
    --criterion gini \
    --train-size 0.8
```

Справка:

```bash
python3 main.py --help
```

Все эксперименты одной командой:

```bash
python3 experiment.py
```

## Эксперименты

Эксперимент 1 обучает дерево на 100% `adult.data` и проверяет на официальном `adult.test` для критериев:

- Information Gain;
- Gain Ratio;
- Gini Index.

Сохраняется `results/criteria_metrics.csv` и изображения:

- `results/trees/information_gain.png`;
- `results/trees/gain_ratio.png`;
- `results/trees/gini.png`.

Эксперимент 2 использует только `adult.data`, делает воспроизводимые стратифицированные разбиения:

- 60% / 40%;
- 70% / 30%;
- 80% / 20%;
- 90% / 10%.

Результаты сохраняются в `results/metrics.csv`, график метрик в `results/metrics.png`.

## Метрики

Положительный класс: `>50K`.

Реализованы вручную:

- Accuracy;
- Precision;

- F1-score;
- TP;

## Возможные ограничения

- Категориальные признаки разбиваются бинарно как `значение` против `остальных`, а не многоветвевым C4.5-разбиением.
- Пропуски удаляются, а не заменяются модой/медианой.
- Для скорости число числовых порогов на признак ограничено параметром `max_numeric_thresholds`.
- Визуализация намеренно показывает первые уровни дерева, а не всё дерево целиком.
